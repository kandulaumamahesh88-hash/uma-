# Sentiment Analysis Project

## 📌 Overview
This project analyzes text sentiments using Machine Learning and NLP techniques.

## 🚀 Features
- Detects positive and negative sentiments
- Uses trained ML model
- Text preprocessing
- Real-time prediction

## 🛠 Technologies Used
- Python
- Scikit-learn
- Pandas
- NLP

## 📂 Files
- app.py → Main application
- train.py → Model training
- dataset.csv → Dataset
- model.pkl → Saved model
- vectorizer.pkl → Text vectorizer

## ▶️ Run Project

Install requirements:

pip install -r requirements.txt

Run application:

python app.py

## 📊 Output
The model predicts sentiment from user text input.
